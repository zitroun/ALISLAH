🤖 ربط الذكاء الاصطناعي عند الاتصال

أضف رابط خدمة آمنة (Backend / Worker). عند توفر الإنترنت سيحاول المساعد استخدامها، وإذا انقطع الاتصال أو فشلت الخدمة سيعود تلقائيًا للمساعد المدمج.

الحالة: المساعد المدمج جاهز. لم يتم ربط خدمة خارجية بعد.

الأمان: لا تضعي مفتاح API داخل هذا الملف أو في GitHub. يجب حفظ المفتاح كـ Secret في الخادم. يوجد ملف worker.js ضمن الحزمة لإعداد Cloudflare Worker.
