# ALISLAH | الإصلاح الذكي

## محتويات الحزمة
- `index.html`: التطبيق مع إصلاح حفظ إجابات الفقاعة وإظهار موافقة واضحة قبل إرسال ملخصها.
- `manifest.json` وأيقونات التطبيق.
- `sw.js`: تخزين ملفات الواجهة الأساسية للاستخدام دون اتصال بعد أول زيارة ناجحة.

## الرفع إلى GitHub من الهاتف
1. افتحي مستودع GitHub الذي ينشر التطبيق عبر GitHub Pages.
2. احتفظي بنسخة من `index.html` القديم.
3. ارفعي محتويات هذه الحزمة إلى جذر المستودع، مع الحفاظ على أسماء المجلدات.
4. انتظري نشر Pages، ثم افتحي الموقع وأعيدي تحميله. إذا ظهرت نسخة قديمة، أغلقي التطبيق المثبت وافتحي الموقع في تبويب جديد أو امسحي ذاكرة التخزين المؤقت للموقع.
5. اختبري الفقاعة: اختاري إجابة وانتظري رسالة «تم حفظ إجابتك»، ثم اضغطي «نصيحة من إجاباتي». يجب أن ينتقل النص إلى المساعد وتظهر موافقة الإرسال بجانب المحادثة. لا يُرسل شيء حتى تفعّلي الموافقة وتضغطي «إرسال».

## ملاحظة
المساعد عبر الإنترنت يعتمد على عنوان خدمة Cloudflare Worker الموجود في إعدادات التطبيق. ملف الواجهة لا يثبت وحده أن خدمة الذكاء الاصطناعي تعمل.
