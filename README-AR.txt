ALISLAH | حزمة التطبيق الكاملة (PWA)

الملفات:
- index.html: التطبيق مع المهام والعادات والأسرة والمساعد الذكي وتحليل العادات والنسخ الاحتياطي وفقاعة الأسئلة العائمة.
- manifest.json: إعدادات التثبيت واسم التطبيق.
- sw.js: التخزين المؤقت لفتح التطبيق عند انقطاع الإنترنت (ميزات الذكاء الاصطناعي تحتاج الإنترنت).
- icons/: أيقونات التطبيق.

طريقة التحديث عبر GitHub من الهاتف:
1) افتحي مستودع ALISLAH في GitHub.
2) نزّلي هذه الحزمة وافتحي ZIP في الهاتف.
3) ارفعي index.html وmanifest.json وsw.js إلى جذر المستودع، ومجلد icons كاملًا.
4) وافقي على استبدال index.html القديم بعد الاحتفاظ بنسخة احتياطية منه.
5) في index.html يوجد ربط manifest وتسجيل Service Worker بالفعل.
6) انتظري حتى يكتمل نشر GitHub Pages، ثم افتحي رابط التطبيق في Chrome.
7) لتحديث النسخة القديمة: أغلقي التطبيق المثبت وافتحي رابط الموقع، ثم أعيدي تحميل الصفحة. إذا استمرت النسخة القديمة، امسحي بيانات الموقع/الكاش من إعدادات Chrome ثم افتحيه مجددًا.
8) من داخل التطبيق > الإعدادات، تحققي من رابط Cloudflare Worker واختبري الاتصال.

الخصوصية والحدود:
- تُحفظ المهام والعادات وإجابات الفقاعة محليًا في المتصفح على هذا الجهاز.
- لا يراقب التطبيق الكتابة خارج التطبيق، ولا يقرأ رسائل أو تطبيقات أخرى.
- إجابات الفقاعة لا تُرسل تلقائيًا؛ راجعي النص واضغطي إرسال بنفسك. تحليل البيانات الشخصية يتطلب موافقة داخل التطبيق.
- الردود الذكية عبر الإنترنت تحتاج اتصالًا بالإنترنت وخدمة Cloudflare Worker صالحة. لا تضعي مفتاح API داخل index.html أو GitHub؛ يجب أن يبقى في Cloudflare Secrets.
- التخزين المحلي قد يُحذف عند مسح بيانات المتصفح؛ استخدمي زر النسخة الاحتياطية دوريًا.

ملاحظة: الحزمة تجمع ملفات الواجهة وPWA، ولا يمكن ضمان خلو أي برنامج من كل الأخطاء قبل اختباره على الجهاز الحقيقي. بعد الرفع، اختبري إضافة مهمة، عادة، سؤال الفقاعة، النسخ الاحتياطي، والاتصال بالمساعد.
